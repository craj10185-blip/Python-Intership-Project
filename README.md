# Python Development Internship Projects - Infotech

This repository contains two core Python projects completed as part of the Python Development Internship at Infotech.

## 🚀 Projects Included:

### 1. PyChronicle (AST-Powered Time-Travel Debugger)
* **Domain:** Developer Tools & Metaprogramming
* **Description:** A time-travel execution tracer that uses Python's `sys.settrace` and SQLite to record variable states at every line of execution, enabling historical code inspection.
* **Files:** `pychronicle.py`, `example.py`

### 2. MeshWeaver (Zero-Dependency P2P Async Task Broker)
* **Domain:** Distributed Systems & Edge Computing
* **Description:** A decentralized, peer-to-peer task queue built purely using Python's `asyncio` framework for distributed workload handling without central message brokers.
* **Files:** `meshweaver.py`
